# STEP配信システム：予約配信（2026-10-12）

配信方法の初期値は「今すぐ配信（通常）」。必要なときに「日時を指定して配信（予約）」を選び、日本時間で配信日時を指定する。最終確認で日時・送信先・件名を確認する。「予約一覧・確認・キャンセル」で予約内容、添付名、処理結果を確認できる。キャンセルは配信処理が始まるまで可能。変更はキャンセルして作り直す。

画面を閉じても配信される。指定時刻を過ぎた最初の定期実行で配信するため、数分程度遅れることがある。予約は1分以上先、1年以内、未配信の予約は最大50件。添付は合計15MB程度まで。

## 保存と実行

- `ScheduledDelivery.gs`：シート「配信予約」に日時・状態・件名・対象生徒・データファイルID・処理結果を保持。本文・添付・宛先情報は作成者の非公開Driveフォルダ「STEP配信予約データ」のJSONに保存し、共有設定を変更しない。
- 予約時に本文、添付、対象生徒、氏名、メールアドレス、校舎電話、送信者名を保存する。配信時にもメール設定の配信停止フラグを適用する。テンプレートの後日変更は予約本文に反映しない。
- 初回の予約保存時に、`processScheduledDeliveries` の1分ごとのトリガーを作成。同じトリガーがあれば追加しない。手動で `installScheduledDeliveryTrigger` を実行して事前設定も可能。
- 同じ予約IDの保存リクエストは同じ予約を返す。実行前に「配信中」をシートに保存・flushし、重複配信を防ぐ。1回の起動で1予約を処理する。
- 異常終了した「配信中」は15分後に「要確認」へ移行。自動再送しない。送信エラーは結果と通常の配信履歴・送信ログで調査する。
- 予約本文のJSONはキャンセル後・配信後も保持し、一覧は完了分の直近20件を表示する。キャンセルによるデータの永久削除は行わない。
